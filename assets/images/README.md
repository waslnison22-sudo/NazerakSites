# Визуальные материалы NaZerak

## Главная страница

Фоновый пейзаж текущего чернового редизайна берётся со страницы Wikimedia Commons:

- **Файл:** [Minecraft - 1.18 mountains.jpg](https://commons.wikimedia.org/wiki/File:Minecraft_-_1.18_mountains.jpg)
- **Указанный автор:** Xbox México
- **Указанная лицензия:** [Creative Commons Attribution 3.0](https://creativecommons.org/licenses/by/3.0/)
- **Использование:** затемнение и лёгкая цветокоррекция через CSS; источник и лицензия указаны в футере главной.

**Ограничение перед публикацией:** страница Wikimedia Commons помечает файл статусом *license review needed*. Поэтому этот визуал — временный источник для дизайн-концепции, а не подтверждённый скриншот сервера NaZerak. До production-публикации нужно проверить права/атрибуцию либо заменить изображение собственным утверждённым скриншотом игрового мира.

## Форум

Файл `forum-hero.svg` используется как абстрактный фон форума. Он не подменяет собой скриншот игрового мира.

## Принцип хранения

Не добавляй декоративные SVG с произвольными орбитами, кругами, треугольниками или сетками поверх главной. Главный визуальный акцент должен быть реальным игровым пейзажем, а интерфейс — опираться на типографику, сетку и понятные интерактивные элементы.
