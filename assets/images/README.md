# Визуальные материалы NaZerak

## Главная страница

- **Текущий фон:** `nazerak-autumn-hero.webp`
- **Использование:** локальный фон hero-блока главной страницы, не внешний ресурс.
- **Обработка:** масштаб и вертикальное позиционирование фона настроены через `home-hud.css`, чтобы скрыть остаточную полосу прежнего макета без замены изображения.
- **Требование:** сохранить выбранный осенний визуал. Не заменять его скриншотом игрового мира при выпуске этой версии.
- **Публичный путь:** `/assets/images/nazerak-autumn-hero.webp`

## Форум

Полная переработка системы и логики форума относится к отдельному следующему этапу после стабилизации релиза главной страницы.

## Принцип хранения

Не добавлять на главную абстрактные орбиты, круги, треугольники или геометрическую сетку поверх hero. Основной визуальный акцент — выбранный осенний пейзаж, типографика и ровная сетка интерфейса.
