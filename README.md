# NaZerak — официальный сайт

Официальный статический сайт проекта NaZerak.

## Структура

- `index.html` — главная страница
- `styles.css` — оформление и адаптивность
- `script.js` — небольшая клиентская логика
- `favicon.svg` — иконка сайта
- `404.html` — страница ошибки

Сайт не использует npm, сборщик или внешние UI-библиотеки.

## Локальный запуск

Обычное открытие `index.html` работает для статической части сайта. Для поведения, максимально близкого к GitHub Pages, можно запустить любой простой HTTP-сервер, например:

```bash
python -m http.server 8000
```

После этого открыть `http://localhost:8000`.

## GitHub Pages

Репозиторий рассчитан на публикацию как статический GitHub Pages-сайт.

После включения Pages для ветки `main` корень репозитория является publish directory.

## Домен

Когда будет зарегистрирован `nazerak.is-a.dev`, достаточно направить его DNS на GitHub Pages и добавить соответствующую настройку custom domain в Pages.

Не добавляйте CNAME в репозиторий до момента регистрации домена, чтобы не закреплять неподтверждённый адрес.
