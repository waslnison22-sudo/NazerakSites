# NaZerak — полный список визуальных ассетов сайта

Это список реальных файлов для сайта, а не макеты интерфейса. Скриншоты-мокапы нельзя вставлять вместо фотографий: браузеру нужны отдельные картинки без HTML, надписей и нарисованных элементов интерфейса.

## Уже подготовлено в коде

| Элемент | Файл | Статус |
|---|---|---|
| Основной знак NaZerak и favicon | `favicon.svg` | Векторный абстрактный знак заменяет буквенную иконку |
| Знак в шапках форума и кабинета | Inline SVG в HTML | Резкий на любом экране, отдельная растровая версия не нужна |
| Интерфейсные иконки | SVG/CSS в интерфейсе | Использовать единый набор иконок, не генерировать каждую кнопку картинкой |
| Главный осенний арт | `assets/images/nazerak-autumn-hero.webp` | Сохранить текущим. Не заменять макетом интерфейса и не переписывать автоматически |

## Не генерировать

- Мокап сайта целиком: это референс композиции, а не веб-ассет.
- Аватары участников: брать из Discord OAuth, не подменять генеративными.
- Иконки всех разделов: оставить векторными и однотипными.
- Фотофоны под длинные сообщения и темы: они ухудшают чтение.
- Отдельные картинки для кнопок, вкладок, ролей и бейджей: это HTML/CSS.
- Новую главную картинку без отдельного согласования. Осенний hero не заменять автоматически.

## Приёмка изображений

1. Каждый арт отдельным файлом, без коллажа, HTML и UI.
2. Нет текста, букв, логотипов, водяных знаков и артефактов.
3. Проверить кропы hero 16:5, 16:9 и узкий мобильный; карточки 4:3 и квадрат.
4. Сохранить мастер-файл; для сайта оптимизировать WebP.
5. Проверить файл на 100%, размер и реальную загрузку из `/assets/images/forum/`.
6. До генерации и одобрения файл не должен упоминаться в CSS/HTML как существующий.
